# Vaulty — explorari logo si favicon

Trei concepte generate cu instrumentul imagegen integrat, pentru alegerea directiei:

1. Editorial Folded V: monograma inspirata de pagini si wordmark serif.
2. Soft Archive: document stilizat, verde sage si wordmark sans-serif.
3. Architectural Monogram: V intr-un cadru deschis, bronz si serif.

Fiecare plansa include logo-ul si doua prezentari ale simbolului de favicon.
Sunt propuneri raster de identitate, nu exporturi finale SVG/ICO sau fisiere favicon
la 16/32px. Dupa alegere se pregatesc activele separate si se verifica lizibilitatea
la dimensiunea reala. Utilizatorul a aprobat varianta 01, Editorial Folded V. Activele finale raster
sunt in selected/, iar exporturile folosite de aplicatie in public/images/brand/.

Prompturile complete sunt in prompts.json. Varianta 01 este activa in antet, footer, panoul utilizatorului si emailurile de cont. Lucrarile la notificari raman pentru etapa urmatoare.
